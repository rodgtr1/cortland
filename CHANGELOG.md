# Changelog

## Unreleased

## 0.7.1 (2026-07-25)

### Fixes

- **Quick Open stays bounded without `fd`**: the stock-macOS fallback walked the whole tree and filtered afterwards, so a repo with a `node_modules` paid for every file in it on every keystroke, and the whole listing was buffered before anything was scored. `find` now prunes `.git`, `node_modules`, `.build`, and `target` instead of descending into them, output is read a chunk at a time and the walk is killed once the 20,000-candidate cap is reached, and a five-second ceiling ends a search rooted somewhere enormous. Results from an abandoned search can no longer reappear: killing `find` doesn't stop the reader that already has most of a large tree, so clearing the field, typing again, or closing the panel now retires the search outright and anything it produces afterwards is dropped. Fuzzy ranking and the 50-row display cap are unchanged.
- **Session Recall scales to a long history**: the title scan streams each log, folds each record into the handful of fields it needs instead of keeping 2,000 of them, and stops at its 2,000-line cap — so the cap now bounds memory and the read, not just the parse, rather than loading a 400 MB transcript to look at its first lines. A single record past 4 MiB (an inlined file read, or a log written without newlines) is skipped rather than assembled. Deep search gained explicit budgets — 64 MiB per transcript, 32 million characters per index — and truncates instead of growing without limit; the per-transcript budget is a ceiling on a single JSONL record too, so a log written as one enormous line is discarded past it rather than assembled whole, and the index trims what it stores rather than letting the first transcript overshoot. Deep queries are debounced and run off the main thread with a generation token, so typing no longer walks every indexed transcript per keystroke and a slow search for "np" can't land on top of the results for "npm install". When a budget did cut something short, the footer says so instead of presenting a partial count as a total.
- **Approval modes say what they do**: both Auto modes auto-approve work *inside the project directory* and prompt when something reaches outside it — including Cortland's own socket at `~/.config/cortland/cortland.sock`, which is why an agent using `cortland-ctl` can still be asked once. The Preferences labels, help text, `config.toml` comments, and README now say that plainly, and that Full access is the mode with no boundary and no prompts.
- **Releases are verified after publishing**: `scripts/verify-release.sh <tag>` downloads a release's public assets and fails unless both DMGs are signed, assessed as notarized, and stapled, the app inside each passes `codesign --verify --deep --strict`, Gatekeeper, and `stapler validate`, the appcast matches the mounted build, and the enclosure URL serves a file. The tag-triggered GitHub Actions release workflow is gone: CI has neither the Developer ID key nor the notary credentials, so everything it built and uploaded was unsigned. The manual path in `docs/release.md` is the release.
- **Build numbers survive 1.0**: the `CFBundleVersion` formula was minor × 100 + patch, which ignored the major component — 1.0.0 would have computed to `0` and Sparkle would have offered 0.7.0 to it as an update. It is now major × 10000 + minor × 100 + patch, which renumbers nothing already shipped (0.7.0 is still `700`) and puts 1.0.0 at `10000`.

- **Dev builds launch again**: the build script applied the hardened runtime to every build, and the hardened runtime enforces library validation — every embedded library must carry the same Team ID as the app. A Developer ID certificate supplies one, so release builds were fine, but the self-signed dev identity has none, and dyld killed the app at launch the moment Sparkle.framework became something to load ("mapping process and mapped file (non-platform) have different Team IDs"). The hardened runtime is now applied only under `RELEASE=1`, where notarization requires it. TCC grants key on the designated requirement, which these flags do not change, so they still survive a rebuild.
- **`./install.sh` no longer breaks the app it installs**: the copy to `/Applications` used `cp -r`, whose legacy recursive mode follows symlinks into real copies. Sparkle.framework is the bundle's first symlinked framework, so the flattened copy failed its code-signature check and dyld killed the app at launch. The installer now copies with `ditto`, the same tool the build uses to embed the framework, for the same reason.

## 0.7.0 (2026-07-24)

### Renamed

- **Sidekick is now Cortland.** Everything user-facing takes the new name: the app bundle and its DMG/zip, the `cortland-ctl` / `cortland-agent-status` / `cortland-mcp` / `cortland-telemetry` helpers, the `cortland` MCP server and its `mcp__cortland__*` tools, the `cortland-panes` skill, the `CORTLAND_*` environment variables, the socket at `~/.config/cortland/cortland.sock`, and the bundle identifier (`app.cortland.terminal`). Earlier entries in this file still say Sidekick, because that is what shipped.
- **Upgrading carries the old install across.** On first launch the app copies `~/.config/sidekick` to `~/.config/cortland` — config, themes, and every arcade journal and almanac — item by item, skipping the stale IPC socket that would otherwise fail the copy outright, and leaving the old directory untouched so the previous build still works. Installing the hooks now also recognises a pre-rename integration and adopts it: the `cortland-*` entries go in and the `sidekick-*` ones come out (in `~/.claude/settings.json`, `~/.codex/config.toml`, the Pi extension, the installed skill, and the registered MCP server), so no event fires twice and none of them fire into a binary that no longer exists.
- The local codesigning identity stays `Sidekick Dev` and the notary keychain profile stays `sidekick-notary`. Renaming the certificate would throw away every TCC grant tied to it, which is the one thing it exists to preserve.

### New features

- **Cortland updates itself.** The app embeds Sparkle 2.9.4 and checks a feed published with each GitHub release, so an installed copy no longer has to be replaced by hand. Nothing installs behind your back: Sparkle asks once whether it may check at all, and every update it finds is shown with its version and release notes and waits for you to press Install. "Check for Updates…" sits under About in the Cortland menu for checking on demand, and stays disabled in builds that carry no feed (an unbundled `swift run`, for instance) rather than failing when clicked.
- **Updates are signed, so a public feed is safe.** Every release archive is signed with an Ed25519 key whose private half never leaves the release machine's Keychain, and each build verifies the download against the public half baked into its `Info.plist`. Whoever controls the download URL cannot substitute an archive: a tampered one is refused before anything is installed. The whole path — feed fetched, update found, archive downloaded, signature checked, app replaced in place — was run end to end over a local server before shipping, including the rejection case.
- **The release flow generates the feed.** `scripts/make-appcast.sh` reads the version off the built bundle (so the feed cannot disagree with what it ships), signs the notarized DMG, and writes `build/appcast.xml`, refusing to finish if the result is unsigned or names the wrong build. `docs/release.md` now carries the full procedure through `gh release create`, including which three files have to be attached and why renaming any of them breaks updates for everyone already running Cortland.
- **Notarized releases**: `RELEASE=1 ./build-app.sh` signs the app, its four helper binaries, and the DMG with a Developer ID identity, hardened runtime, and secure timestamps; `scripts/notarize.sh` submits the app to Apple, staples the ticket, rebuilds the zip and DMG from the stapled app, then notarizes and staples the DMG too. A downloaded copy passes Gatekeeper on first launch, even offline, with no right-click override. Dev builds still sign with the local identity so TCC grants persist across rebuilds. `CFBundleVersion` carries a monotonic build number (major × 10000 + minor × 100 + patch) separate from the human-facing version, which is the number Sparkle compares to decide an install is out of date.
- **Session Recall filters by agent**: an All/Claude/Codex segmented control (⌘1/⌘2/⌘3) sits beside the Deep toggle and applies ahead of the text query in both shallow and deep search, so the footer counts reflect the filtered set.
- **Changed images preview in the git panel**: a modified image used to render as an empty text diff because git reports it as binary. The uncommitted-changes panel now shows the working-copy picture itself — scaled proportionally, capped at 360pt tall, captioned with type, pixel size, and on-disk bytes. Covers png, jpg, gif, heic, webp, tiff, bmp, ico, icns, and svg; anything AppKit can't decode falls back to the text diff.
- The app has an icon.

### Fixes

- **⌘+click on a link opens one browser tab, and schemeless links open at all**: the press was forwarded to the child process as a plain click (the xterm protocol has no bit for Command), so an agent on the alternate screen could open the same link again, and SwiftTerm's own handler raced the app's, doubling tabs on the normal screen too. Link opening now has one owner — every path funnels through the same normalizer and a short-window dedupe — and a bare `host/path` link is promoted to https when its first segment reads as a hostname, so `developers.cloudflare.com/docs` opens while `src/main.rs` stays refused.
- **Reading a pane that is running a full-screen program returns its screen instead of a scramble**: an agent CLI, vim, or lazygit repaints by moving the cursor and rewriting cells rather than printing lines, so stripping the escapes from the raw byte stream welded thousands of frames onto one line, and the redraw collapse then kept only the last fragment of it. Alternate-screen reads now come off the emulator. A full read is the main screen's retained scrollback — everything printed before the program took over — followed by the current interpreted frame; a delta read is that frame when bytes have arrived since the caller's cursor, and empty when none have, because a repaint overwrites cells in place and leaves no "what is new" to diff. The cursor keeps its usual job of detecting that output happened, and a tight `--lines` budget now spends itself on the frame a human would actually be looking at.
- **Live theme switches repaint all of Preferences**: switching themes recolored each pane's outer layer but left scrolled content on the old theme; the repaint now walks scroll views, clip views, and document views too.
- **Depth Ladder: filling a crossed cell lifts the cross instead of doing nothing**: a stray cross on a cell the solution fills made a floor look uncompletable. The first press now clears the cross, free, so the second press lands.

## 0.5.0 (2026-07-20)

### New features

- **Session Recall**: `⌃⇧S` opens a searchable panel over every Claude Code and Codex session on the machine, across all repos, newest first, answering "I did something with an agent days ago and can't find the conversation". Rows show a one-line title, repo, and age; Enter resumes the selected session in a new tab already sitting in the session's original working directory (the resume command is passed as argv, so the configured approval level still applies), and the 50-row cap is visible in a footer count rather than silently truncating. Built with no database and no network: Swift parsers read both agents' own session logs (pinned by golden fixtures for the format landmines: Codex prompts arrive on two channels, the encoded Claude project-directory name is a lossy cwd source and is never trusted), behind an mtime-keyed JSON cache that re-parses only changed files.
- **Transcript preview**: `⌘↩` on a selected session opens a read-only floating transcript (You/Claude/Codex/tool turns, commands in monospace, tool outputs omitted) with selectable text, so a remembered command can be re-read and copied without resuming anything. The list stays open behind it.
- **Deep search**: a Deep toggle switches the search from titles to the inside of transcript bodies (prompts, replies, and the commands the agent ran; bulk tool outputs are skipped), with the matching line shown as each row's subtitle. The body text is read into memory off the main thread on first use, searched as you type, and freed when the panel closes; nothing is persisted and there is no SQLite.
- **Codex sessions get real titles, once each**: Claude sessions reuse the `aiTitle` Claude itself writes into the log; Codex sessions generate a one-liner through a local Ollama model (`--think=false`, one serial background call at a time, 60s cold-load timeout) that is persisted in the cache so each session is titled at most once ever. Any failure silently keeps the raw prompt. Codex rollout files also dedupe to one row per session (the root thread wins over subagent threads), and Sidekick now records an append-only launch ledger (agent, cwd, branch) whenever it starts an agent, which backfills the rare session log that never recorded a working directory.
- **Journal, an arcade game of bounded writing prompts**: agent work is ask, wait, inspect, judge; the journal inverts that for a few minutes at a time (notice, write, finish) with a size limit that promises closure rather than setting a target. Three doors (clear my head, make something, reflect), a meter that measures space instead of time and never blocks typing, and one plain markdown file per month in `~/.config/sidekick/journal` that the user owns. Drafts survive closing the panel; nothing tracks streaks or asks twice.

### Fixes

- **Wrapped workers keep the approval mode**: a pane launched as `--exec sh -c 'exec claude …'` hid the agent program from the approval-flag argv injection, and the inner non-interactive shell never defines the `claude()` wrapper, so the worker silently started in manual mode while every interactive launch honored the configured level. Sidekick now writes `claude`/`codex` PATH shims to `~/.config/sidekick/shims` (refreshed at launch, like the shell integration) and the worker launch script prepends them to PATH after rc files run, so whichever process in a worker's tree finally resolves the agent CLI still applies the live approval mode. Explicit caller flags always win, a missing mode file fails closed to ask, and the shim strips itself from PATH by physical path so a symlinked entry can't make it exec itself.
- **Auto-reviewed Codex panes no longer claim to need input**: in review mode Codex fires PermissionRequest for every command, but `approvals_reviewer=auto_review` answers without the human ever typing, so the pane parked on "Needs input" until the next tool call. The payload doesn't name the effective reviewer, so each launch site now stamps the active reviewer into the codex process for its hooks to inherit, and the helper downgrades ready accordingly.
- **Arcade grid sizing no longer crashes the string-drawing engine**: a live Cartography draw pass could abort with an uncatchable exception from inside `sizeWithAttributes:` when the font service returned nil mid-measurement. Cartography, Grove, and Keysmith now read the glyph advance straight from CoreText via a shared ArcadeTypography helper.

## 0.4.0 (2026-07-16)

### New features

- **Agent file edits go through the approval desk**: Claude Code's PreToolUse hooks can now answer the permission question outright, so a new edit-gate feeds Edit/Write calls through the F3 diff-review desk and the desk's verdict replaces Claude's own prompt instead of doubling it. One prompt total; a desk deny holds even under bypassPermissions, which makes `always_ask` rules like `.env` genuinely safe in auto mode; any failure (Sidekick down, unparseable input, oversized or binary body) fails open to Claude's own prompt so an agent is never bricked. Pi's edits ride the same desk through its extension API, with block-with-reason on reject so the agent adjusts instead of retrying blind. Codex is excluded on purpose: its hooks are verified deny-only, so an approve cannot suppress Codex's own prompt, and the README now states that honestly. The desk is hardened for real use: a hook that dies while its edit waits (killed agent, closed pane, 600s timeout) has its card withdrawn the moment the socket hangs up, parked edits flip the pane to needs-input and back, and always-ask cards say so instead of offering remember options that do nothing.
- **The Arcade**: ⌃` toggles a floating popup arcade, strictly opt-in (`[arcade]` in config.toml or Preferences > Extras), hosting ten self-contained games that round-trip their whole state through `arcade.json`, so hiding the panel or relaunching never loses a board. Three are deliberate brain work: Blocks, Depth Ladder (an endless nonogram tower whose generator rejects any floor that would require guessing), and Keysmith (a typing trainer that drills whichever keys you actually miss). Seven are rest, built with no scores, no streaks, and no fail states: Two Lines, The Grove, The Walk, Slow Cartography, The Pond (the catch is decided entirely at reel-in, so nothing that happens while away can be missed), Loom (tile-turning where no move is ever a mistake), and Night Sky. Keepsakes are plain markdown files the user owns, and every game explains itself with a help overlay.
- **Claude/Codex permission parity**: the shared approval selector now maps the same four intents onto both agents. Codex Ask now deliberately starts stricter than before (read-only), so writes and other boundary crossings require approval instead of inheriting a potentially permissive global Codex default. Auto uses workspace-write, safety-reviewed Auto uses Codex's `auto_review` reviewer, and Full Access uses danger-full-access with no prompts. Preference changes apply to the next agent launched in an already-open pane, while the UI now identifies path-specific diff-desk rules as Claude/Pi-only.
- **Claude's Auto mode as a fourth approval level**: the newer `--permission-mode auto` (auto-approve behind a safety classifier that blocks destructive or off-task actions) is now a first-class level in the Approvals popup instead of something you hand-type per pane. Scoped to Sidekick-launched sessions like the other modes; the session toggle (⇧⌘A) never downgrades it.
- **Skills opt into the command palette**: a `sidekick-palette` tag in a skill's SKILL.md frontmatter puts it in ⇧⌘P; installing or untagging one needs no app change. Argument-less skills can tag themselves to submit immediately, others leave the cursor waiting for arguments. User and workspace skill roots are both scanned, workspace shadowing user on name collisions, matching the agents' own precedence.

### Fixes

- **Answered prompts no longer stick on "Needs input"**: Claude Code fires no hook at the moment a prompt is answered, so an approved tool could run to completion with the pane still flagged. The hook contract gains PostToolUse/PostToolUseFailure as the earliest authoritative busy signal, and the answer keystroke itself (Enter or a bare option digit only) optimistically flips ready back to working for the gap hooks cannot cover. Launch reconcile upgrades existing installs, and the hook-install script is realigned with the app installer so it stops rewriting the same file every launch.
- **Clicks no longer answer agent prompts**: Claude Code keeps mouse reporting on for its inline prompts, so a click meant to focus a pane could land on an option row and silently select it. Clicks on the normal screen are never forwarded as mouse reports, and the click that switches pane focus is swallowed even on the alternate screen; deliberate clicks in an already-active alt-screen app (vim, lazygit) still work.
- **The first tab honors the configured approval level**: approval state synced after the initial tab had already spawned, so the first pane's agent launched in manual mode while every later pane obeyed the configured Auto level.
- The sidebar resize handle no longer drags the whole window along with the resize.
- Git panel filenames truncate later, so status rows stay readable.

### Removed

- **The Commands sidebar panel is gone**: a timeline of non-agentic shell commands that never got opened in practice. The OSC 133 command recorder stays; agent status detection, completion notifications, prompt jumps, and `pane read --json` all still feed off it.

## 0.3.0 (2026-07-13)

### New features

- **Close confirmation**: Cmd+W (close tab) and Shift+Cmd+W (close pane) now ask before killing sessions, calling out any agents still working there. On by default; disable in Preferences > General or with `confirm_close = false` under `[behavior]`. The built-in editor joins in: an unsaved buffer prompts Save / Cancel / Discard on every close path (pane or tab close, window close, quit) instead of being silently discarded.
- **Upgrades complete themselves**: whichever way you install, the agent integration keeps itself current. An installed app refreshes the `~/.local/bin` helper binaries on launch when they differ from the bundled copies (atomic swap, never creating absent ones), re-syncs the bundled `sidekick-panes` skill the same way, and brings existing hook entries up to the current contract when the hook vocabulary grows (Claude Code, Codex, and Pi). From source, `./install.sh` finishes by re-running `scripts/install-agent-status-hooks` (new `--refresh-only` and `--binaries-from DIR` flags) against the app it just installed, so there is no second build and no follow-up command. Nothing ever bootstraps an integration you didn't opt into, and hook dedup now keys on helper name plus arguments so the two install paths recognize each other's entries.
- **Versioned status handshake**: the `agent_status` report now carries a wire-protocol version. A pane whose hook speaks an older protocol than the app flags it once, in the pane and in the log, instead of failing silently; reports are always honored whatever version they declare.
- **Readable pane transcripts**: recent pane reads return a normalized transcript (escape chatter stripped, each spinner's carriage-return overwrite run collapsed to its final frame) instead of the raw redraw stream; a 20-line read of a spinning TUI dropped from 19.5KB to 1.2KB. Full reads are served from the interpreted screen, and the normalization work runs off the main thread.
- **Ghost text marked in pane reads**: autosuggest completions (Claude Code, fish/zsh) rendered at the cursor are wrapped in an explicit "suggested, not typed" marker in visible reads, so monitoring agents stop attributing suggestions to the user.
- **Live tab drag-reorder**: dragging a tab now works while agents are busy (the tab bar's refresh storm no longer snaps the dragged tab back), and the other tabs slide out of the way live to preview where everything lands on release.

### Fixes

- **Editor data-loss guards**: saves check the file's modification date so you can't silently overwrite an agent's concurrent edit, write through symlinks instead of replacing them with regular files, and keep the file's original encoding, asking before any fallback to UTF-8.
- **Agent status reaches the app from tty-less hooks**: Claude Code spawns hook processes detached from the terminal, so every status report died on `/dev/tty` and panes drifted on text heuristics that misread Claude's spinner as idle. The hook now falls back to the control socket with the same authority, fixing `wait agent-status` monitoring.
- **Symlinked directories expand in the file tree**: linked folders (pnpm `node_modules`, linked packages) rendered as unexpandable files; they now classify and enumerate through the resolved target. The expanded-folder icon also draws again ("folder.open" is not a real SF Symbol).
- **Search results say what actually happened**: outcomes are explicit (complete, capped at 1000, stopped at the 8s timeout, failed), a killed or failed search no longer renders partial or stale rows under a confident count.
- **Structural edits recolor the whole file**: the tree-sitter highlighter keeps the document's tree, reparses incrementally, and recolors whatever the edit restructured, so deleting a brace or opening a quote no longer leaves the rest of the file wearing the old parse's colors.
- Five small data-loss and staleness bugs: a corrupt `session.json` is preserved as `session.json.bak` instead of being overwritten by the next autosave; the shell-integration installer no longer treats an unreadable `~/.zshrc` as empty (and would have replaced it); stale terminal titles and a mispinned branch watcher from out-of-order cwd lookups; Search and Quick Open no longer deadlock a child process on an undrained stderr pipe; a ConfigWatcher fd close race.
- The log is bounded: one held handle, rotation to `Sidekick.log.1` at 5MB, and debug records gated behind `SIDEKICK_LOG_LEVEL`.
- Untrusted text is no longer taken at face value: a git filename containing " -> " no longer truncates in the git panel, and an SSH config alias must look like a host token before it is ever typed into a shell.
- CommandRecorder stops capturing alternate-screen output, so a full-screen TUI's redraw noise no longer fills the 256KB command record.

### Performance

- Tab-bar rebuilds no longer eat clicks: under an active agent, per-second title refreshes rebuilt every tab button and a rebuild landing mid-click silently swallowed the selection; buttons now update in place.
- The git panel stops refreshing on every prompt: cwd reports resolve through a memoized repo lookup instead of forking `git rev-parse` on the main thread and restarting the FSEvents watcher each time, and Stage/Unstage flips the row the moment git returns.
- File-tree rebuilds are off the main thread's back: scans that come back structurally identical to what's on screen are dropped (the common agent workload now costs nothing), re-expansion is batched, and first-time expansion of a large folder inserts only the new rows instead of rebuilding every descendant.

## 0.2.0 (2026-07-03)

### New features

- **Worktrees as workstreams**: a Worktrees sidebar panel with review-vs-main, git panel retargeting, and a one-click merge action. `pane split --worktree <branch>` creates or reuses a worktree for the pane, worktree lifecycle is scriptable over MCP (`sidekick_worktree_list` / `remove` / `prune`), and worktree tabs get a muted glyph in their titles.
- **Agent edit review queue**: agent file edits queue in a sidebar panel for review instead of interrupting with a blocking sheet, with worktree-scoped auto-approve so a trusted worker's edits inside its own worktree flow through.
- **Native notifications (opt-in)**: attention events can mirror to macOS notifications: agent needs input, agent finished, command failed out of view, long-running command finished. Everything is off by default; enable per event in Preferences or the `[notifications]` config section. Sidekick never notifies while frontmost, never steals focus, withdraws stale alerts, and names the failing command in the notification body.
- **Failed commands join the attention cycle**: a command exiting non-zero in a pane you aren't viewing lights a "Command failed" row in the Agents panel and joins the Shift-Cmd-J cycle; it clears when you visit the pane or its next command succeeds.
- **Command timeline**: a Commands panel built from shell-integration (OSC 133) records; every command's exit code, duration, and output per pane, also available as structured JSON via `pane read --json`.
- **Cost telemetry**: per-tab cost roll-up in the Agents dashboard with per-pane, per-model attribution, plus a JSONL session cost history on disk.
- **Fleet status in one call**: the `sidekick_agent_list` MCP verb and `sidekick-ctl agent-list` return every active agent pane's state, elapsed time, cost, and worktree at once.
- **Event waiting for orchestrators**: `sidekick_wait_event` over MCP and `sidekick-ctl wait event` block until the next agent-state, command, or diff event.
- **Codex parity**: scoped approvals and lifecycle hooks now work for Codex workers, not just Claude.
- **Delta pane reads**: `pane_read` supports cursor-based reads that return only output since the last read.

### Fixes

- `pane_split` and `new_tab` no longer hang (IPC file descriptors leaked into forked pane shells).
- Cost telemetry was inflated roughly 2.2x; now attributed accurately per pane and model.
- `pane run` no longer has its Enter swallowed by TUI apps; it is sent as a separate keystroke.
- Preferences window no longer clips tall content; every tab scrolls and the window is resizable.
- Dead panes: the close button works, and waits no longer outlive their pane.
- IPC hardening: pool exhaustion, fd reuse, SIGPIPE, and latched-state bugs.
- Agent-edit approval hardening and config-integrity protection.
- Keyboard chords match exactly instead of loosely.

### Internal

- Two full multi-agent code-review sweeps resolved: critical bugs, perf work off the scroll/render hot paths, dead-code removal, dependency pinning.
- Major refactors: agent-state machine extracted from the terminal controller, git plumbing consolidated behind GitService with a single FSEvents watcher, palette registry and preferences form builder extracted, eventing consolidated.
- Tests added for previously zero-coverage risky modules.
