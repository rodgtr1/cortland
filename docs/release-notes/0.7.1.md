# Cortland 0.7.1

This release makes Cortland safer on large repos and long agent histories.

## Faster searches

- Quick Open now prunes dependency and build folders, reads results in chunks,
  and stops slow searches. Clearing or changing a query also blocks late
  results from an old search.
- Session Recall now limits the memory used by large logs and its deep-search
  index. Deep searches wait for a short pause in typing and run off the main
  thread.

## Clearer controls

The two Auto approval modes now say that they apply inside the workspace.
Actions outside it can still prompt, including access to Cortland's control
socket. Full access removes both the sandbox and those prompts.

Release downloads now state that they require an Apple Silicon Mac.

## Safer releases

Cortland now checks every public release after upload: both DMGs must pass code
signing, Gatekeeper, notarization, and stapling checks, while the appcast must
match the app. The unsigned CI release path has been removed.

Build numbers now stay ordered across major versions, so a future 1.0 update
cannot rank below a 0.x build.

Full detail in [CHANGELOG.md](https://github.com/rodgtr1/cortland/blob/main/CHANGELOG.md).
