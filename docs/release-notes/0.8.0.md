# Cortland 0.8.0

This release adds session handoff for agents, completes the Catppuccin theme family, and fixes a run of terminal, editor, and Git panel annoyances.

## Continue in Fresh Session

A new entry in the tab right-click menu and the command palette hands an agent's work from a nearly full session to a brand-new one. Cortland asks the agent to write a handoff document, waits for it to finish, and opens a new tab in the same directory running the same CLI with a prompt to read it and continue. The original tab stays open. The handoff prompt is configurable under a new `[handoff]` section.

## Themes

Frappé and Macchiato join Mocha and Latte. Light themes got a readability pass: muted text and terminal grays now meet a documented contrast contract that built-in themes are tested against and user themes are warned about.

## Terminal

- Text can be selected and copied over Codex and other apps that keep mouse reporting on. A plain drag selects on the normal screen, Shift-drag selects over full-screen apps, and a selection survives the app redrawing in place.
- The `scrollback_lines` setting is now applied. Panes previously kept 500 lines of history regardless of the config.
- Files and images can be dropped on a pane; each path is typed in quoted.
- Clicking a file path opens it in the editor without a stray Finder alert, including paths wrapped across rows and files on the git diff screen.
- Kitty keyboard flags reset at every prompt, so a crashed TUI can't wedge key input.
- New tabs open next to the current tab.

## Editor and Git panel

- Line numbers stay visible after scrolling past the first screen.
- ⌘↩ commits only while the commit message box has focus.
- Long pull and push output scrolls inside the alert instead of pushing the OK button off-screen.
