# Cortland 0.9.0

This release turns the changes pane into a place to review an agent's work, adds extensions, and gives the built-in editor live reload, formatting, and a Markdown reader.

## Reviewing an agent's work

- The changes pane follows the repository live and keeps your place. File sections collapse and carry a Viewed checkbox, a file list at the top jumps to any file, and the diff gutter sits beside the code so a copy yields clean code.
- A switch along the top scopes the diff to Uncommitted, This turn, or This session. Cortland snapshots the working tree when a hooked agent starts a turn, without touching your index, HEAD, or branches.
- Rewind restores the working tree to the start of the turn or session, tells the agent what changed, and can be undone once.
- Review from the keyboard: `j`/`k` walk changes, `J`/`K` files, `v` marks Viewed, `s` stages, `c` comments on lines. Comments go to the agent as one prompt.
- When an agent finishes a turn that changed files, the changes pane opens beside it without taking focus. Preferences ▸ Agents picks a split, a background tab, or off.
- The Agents panel shows how many files each agent changed this turn.

## Extensions

A sidebar panel and command palette entries for another tool are now a folder with a manifest and one executable in any language. Cortland runs it as a separate process and draws the JSON it prints. Install from a git URL in Preferences ▸ Extensions; extensions start disabled. `docs/extensions.md` is the guide for authors.

## Editor

- An open file with no unsaved edits reloads in place when it changes on disk.
- Format Document (`⇧⌥F`) runs the formatter the project already uses.
- Markdown read mode (`⇧⌘M`) renders a `.md` file for reading.
- `⌘L` sends the selection to the agent working in that repository, with your instruction.
- The file tree has a Refresh command.

## Fixes

- Programs can copy to the clipboard with OSC 52 (tmux, Neovim, Helix, the agent CLIs).
- A file name can no longer inject shell commands when opened in a terminal editor.
- Discarding staged new files and renames works; removing a worktree and closing a pane over the control socket no longer lose unsaved or uncommitted work quietly.
- A build or an `npm install` no longer makes every pane and panel run git on each write.
- Git failures are reported instead of showing an empty list, and a broken `config.toml` no longer reverts your settings.
- Clicking the commit message box focuses it, and About Cortland works.
