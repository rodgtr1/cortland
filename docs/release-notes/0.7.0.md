# Cortland 0.7.0

Sidekick is now Cortland, and this is the first build that can update itself.

Install this one by hand, as usual. From here on the app takes care of it.

## Cortland updates itself

The app checks for new releases and installs them in place. Nothing happens
behind your back: it asks once whether it may check at all, and anything it
finds waits at a dialog showing the version and what changed until you press
Install. "Check for Updates…" sits under About in the Cortland menu when you
want to look now.

Every release is signed with a key that never leaves the release machine, and
each build checks the download against the public half baked into it. An
archive that has been tampered with is refused before it is installed, so it
does not matter that the feed itself is a plain public URL.

## Sidekick is now Cortland

The app, the DMG, the `cortland-ctl` and `cortland-mcp` helpers, the MCP
server and its tools, the skill, the `CORTLAND_*` variables, and the socket at
`~/.config/cortland/cortland.sock` all take the new name.

Your old setup comes with you. On first launch Cortland copies
`~/.config/sidekick` to `~/.config/cortland` — config, themes, and every arcade
journal and almanac — and leaves the original alone, so the previous build
still runs. Installing the hooks swaps a pre-rename integration over rather
than stacking on top of it, so no event fires twice and none fire into a binary
that has moved.

## Also new

- **Notarized releases.** The app, its helpers, and the DMG are signed with a
  Developer ID and notarized by Apple, so a downloaded copy opens on first
  launch without a right-click override, even offline.
- **Session Recall filters by agent.** An All/Claude/Codex control (⌘1/⌘2/⌘3)
  narrows both shallow and deep search.
- **Changed images preview in the git panel.** A modified png, jpg, heic or svg
  shows the picture itself instead of an empty binary diff.
- **The app has an icon.**

## Fixes

- Reading a pane running vim, lazygit, or an agent CLI now returns what is on
  the screen. It used to come back as a scrambled fragment, because those
  programs repaint by moving the cursor rather than printing lines.
- ⌘+click on a link opens one browser tab instead of two, and a bare
  `host/path` link opens at all.
- Switching themes repaints scrolled content in Preferences instead of leaving
  it on the old colors.
- Depth Ladder: filling a crossed cell lifts the cross instead of doing
  nothing, so a stray cross no longer makes a floor look uncompletable.
